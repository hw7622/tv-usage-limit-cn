|---|---|---|---|---|---|---|---|---|---|

| 英语 | — | **18** | 8 | 3 | 3 | 4 | — | — | — |
| 科学 | — | — | 5 | 5 | — | — | — | — | — |
| 物理 | — | — | — | — | — | — | — | 8 | — |

消耗量算法：日限 180 分 ÷ 每组 10 分 × 每组 3 道 = 54 道/天；数学占 55%（生成器），
剩约 24 道由语文、英语均分 → **单科每天约 12 道**。二年级语文 38 道，三天转完一圈。

目标不变：**每个启用的 (科目, 年级) ≥ 150 道，一周内不撞同一道题**。

### 策略：自编为主

题目由项目自己编写、随源码以 CC BY-SA 4.0 发布。不走「灌别人的库」这条路，三个理由：

1. **许可**：第三方数据能不能用，取决于上传者有没有权利授权，MIT / Apache 也解决不了
   「他到底有没有权给」。不打包就没有这个包袱。
2. **体积**：几个大源的题都塞在 GB 级 Release 包里（带音频、插图），抽题库还得另写脚本。
3. **质量**：教材配套题大量依赖插图、短文、上下句，电视上根本答不了，清洗成本比自编还高。

仓库只提供工具和格式，谁想用第三方源就自己下载、自己转（见 [QUIZ_FORMAT.md](QUIZ_FORMAT.md)）。
出了问题也只影响他那一份，不会污染整个项目。

### 自编题规范

写成规范是为了批量编题时不用每题重新想，也是为了孩子做题时不至于被题目的毛病带偏。

1. **一题一个知识点**，`knowledge` 字段写具体（拼音 / 量词 / 字形 / 词义），错题加权靠它。
2. **选项 4 个，同一范畴、长度相近**。问「哪个是水果」，干扰项就得是别的水果或蔬菜，
   不能是「桌子」「铅笔」——那不用想也知道。
3. **不用「以上都对 / 以上都不对」**，也不用否定式提问（「下列哪个不是」），孩子容易看漏。
4. **题干 ≤ 26 字，选项 ≤ 16 字**。超了电视上会折行；硬上限是 60 / 30，工具直接丢。
5. **不依赖图片和上下文**，不出现「如图」「阅读短文」「根据材料」。
6. **解析写「为什么这个对、那个错」**，一句话，别写「选 A」——重排选项后会对不上号
   （工具检测到这种写法会跳过该题不重排）。
7. **正确答案别总放第一格**。见下节。
8. 数学不用编，有生成器；要加也是加生成器的题型。

### 已经踩过的坑：答案几乎全在 A

第一次体检发现 **120 道题里 128 个答案是 A（96%）**，等于孩子一路按左键就能过，
门禁形同虚设。原因很简单：手写题时「正确项放第一个」是最省事的写法。

已用 `tools/import_bank.py rebalance` 打散：按 (科目, 年级) 分桶，
保留正确选项内容、只改它站哪一格，重排后分布 31% / 28% / 23% / 18%。
校验过 120 道老题的正确项内容零变化（86 道挪了位置）。

`check` 现在会打印答案分布，任一项超过 45% 就告警。**以后每批新题编完都要跑一次 rebalance。**

### 编题工作流（工具已完成）

```bash
# 1. 导出成表格
python tools/import_bank.py export app/src/main/assets/quiz/bank.json -o 题库.csv
# 2. 在 Excel / WPS 里加题（每行一道，格式见 QUIZ_FORMAT.md）
# 3. 转回 JSON
python tools/import_bank.py convert 题库.csv -o tmp/new.json --source 自编 --license "CC BY-SA 4.0"
# 4. 打散答案位置
python tools/import_bank.py rebalance tmp/new.json
# 5. 合并进题库（自动去重、接着编号）
python tools/import_bank.py merge app/src/main/assets/quiz/bank.json tmp/new.json \
    -o app/src/main/assets/quiz/bank.json
# 6. 体检
python tools/import_bank.py check app/src/main/assets/quiz/bank.json
```

工具还会拦下这些：选项超过 4 项、答案不在范围内、题干超 60 字、含「如图/阅读短文」、
科目不在白名单、年级越界、题干归一化后重复。规则表和阈值理由见 [QUIZ_FORMAT.md](QUIZ_FORMAT.md) 第 5 节。

### 扩充节奏（建议）

按「用得到的先补」排，别一次铺满九个年级：

1. **二年级语文 38 → 150**（当前实际在用的组合，缺口最大）
2. **二年级英语 18 → 150**
3. 三到六年级语文、英语各 100 道（覆盖到高年级也不至于抽样全是同年级）
4. 初中物化生史地政每科每级 50 道（用得少，够抽就行）

每批 50 道左右，编完立刻 `rebalance` + `check`，别攒着一次性导——出问题时好定位是哪批。

### 参考源（不随仓库分发）

想自己转的话，这几个源质量相对靠谱，许可也宽松。**只列方向，仓库不含任何这些数据。**

| 项目 | 内容 | 许可 | 备注 |
|---|---|---|---|
| [ChinaTextbookStudyFree](https://github.com/wuwangzhang1216/ChinaTextbookStudyFree) | 小学 1–6 语文/数学/英语/科学，6545 道单元练习，AI 生成后人工审 | **MIT** | 权利链条最短。数据在 2GB+ 的 Release 包里，得先抽题库 |
| [CSQ](https://github.com/D-Lee419/CSQ) | 小学科学 12000 道，带知识点与解题思路 | **Apache-2.0** | 只补科学，量很足 |
| [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy) | 13335 道，含小学语文 2728、英语 3164，对齐课标带解析 | **CC BY-NC 4.0** | 题最全，但非商业；自己用没问题，别对外宣称可商用 |
| [E-EVAL](https://github.com/AI-EDU-LAB/E-EVAL) / [TAL-SCQ5K](https://github.com/math-eval/TAL-SCQ5K) | 4351 / 5000 道 | **无 LICENSE** | 默认版权保留，不建议用 |
| Nexdata 系列 | 千万级题库 | 商业许可 | 要买 |

关于 CC BY-NC：它约束的是使用行为，且没有 ShareAlike，不会传染代码的 Apache-2.0 许可。
个人自用、免费发布属于 NC 允许的范围；限制在于不能替下游授予商用权。
自用可以，别把数据塞进发行包、也别声称「本仓库全部可商用」。

### 家长端「题库管理」功能（尚未实现）

现状：题库写死在 `assets/quiz/bank.json`，家长完全改不了，想加题只能重新打包。

设计（按 TV 交互约束来，不要照搬手机思路）：

**入口**：家长设置 → 「题库管理」（放在答题门禁页底部，或家长首页独立卡片）

**信息展示**（只读部分）
- 当前题库：来源、版本、总题数、导入时间
- 科目 × 年级题数矩阵（一格一个数字，题数为 0 的格子标灰）
- 最近 7 天出题去重率（从 `EventLog` 算，衡量「够不够用」）

**三个操作**
1. **从 U 盘导入**（TV 上最现实的方式）
   - 用 `ACTION_OPEN_DOCUMENT` 选 `.json`；没有文件管理器时给路径输入框兜底
   - 导入前校验 → 展示「将导入 1280 道，替换现有 120 道，语文二年级 30→210」这样的差异确认页
2. **从局域网地址导入**（家长在电脑上放好 json，电视填 URL）
   - `<input>` 在 TV 上难用 → 提供「手机扫码/局域网推送」二期再做，一期支持直接填 URL
3. **恢复内置题库**：删掉 `filesDir/quiz/bank.json`，回落到 assets

**校验规则（失败必须原样保留旧库）**
- JSON 解析失败 / 缺 `questions` 数组 → 直接拒绝
- 单题：`subject` 在白名单内、`grade` 1–9、`options` 2–4 项且非空、`answer` 在 `options` 范围内、`stem` 非空且 ≤ 60 字
- 全库：题数 1–5000，文件 ≤ 2 MB，`id` 唯一
- 写盘用「先写 `bank.json.tmp` → 校验通过 → 原子 rename」，中途断电不毁库

**生效方式**
- 运行时题库查找顺序：`filesDir/quiz/bank.json` → `assets/quiz/bank.json`
- `QuestionBank` 现在在 `object` 里缓存解析结果；要加 mtime 校验，改了自动重载
- **正在答题的会话不替换**：`QuizGate.session` 已经持有题目对象，等这组答完自然切到新库

**Schema v2 建议**

```json
{
  "version": 2,
  "source": "builtin | ctsf | csq | user",
  "license": "MIT",
  "retrievedAt": "2026-11-07",
  "questions": [
    {
      "id": "chinese-g2-0000",
      "subject": "chinese",
      "grade": 2,
      "knowledge": "拼音",
      "stem": "「蜻蜓」的「蜓」读第几声？",
      "options": ["第一声", "第二声", "第三声", "第四声"],
      "answer": 1,
      "explain": "蜓读 tíng，第二声，也是后鼻音。",
      "difficulty": 1,
      "source": "builtin"
    }
  ]
}
```

新增字段全部可选，老文件不迁移也能读——不要为了 schema 完美去动数据库或强制升级。
